你真正应该记住的

一段同步代码先跑完。 到微任务检查点时，队列里的微任务会一直执行到清空，即使执行过程中又增加了新的微任务。之后浏览器才有机会处理其他任务和渲染。

别把 setTimeout(fn, 0) 理解为“立刻执行”；也别把这张图当成所有浏览器任务源的完整调度规则。
