# 肆.3.3 Sublime Text 还有必要学习吗？

Sublime Text 是轻量、响应快速的文本与代码编辑器。即使团队主力使用 VS Code，了解 Sublime Text 也有价值：快速浏览超大文本、简单批量编辑、临时处理配置文件时，轻量编辑器仍有使用空间。

## 01. 它擅长什么？

- 快速搜索文件与符号，以及多选区编辑。
- 项目文件夹管理、文本替换、代码高亮。
- 通过 Package Control 等机制扩展功能。

## 02. 与 VS Code 怎样选？

VS Code 的调试、语言服务器集成、终端和远程开发生态通常更完整；Sublime Text 强调编辑体验与轻量性。两者没有“必须二选一”的教条，实际取决于团队规范、语言支持和个人工作流。

## 03. 两个实用技巧

**多选相同词**：通过编辑器的查找与多选功能批量处理局部命名，但跨文件语义重命名应使用具备语言分析能力的工具。

**正则搜索**：文本替换前先预览命中范围；涉及 JSON、源码语法结构或跨文件 API 变化时，正则替换很容易误伤字符串与注释。

## 04. 面试官真正关心的事

工具是手段。拿到一个陌生项目，你能否快速理解依赖关系、准确调试、稳定格式化和运行测试，比回答“我到底用哪个编辑器”重要得多。
