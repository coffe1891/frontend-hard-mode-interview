# 壹.2.14 模块化开发

## 壹.2.14.1 老一辈前端工程师如何实现模块化

在 ECMAScript 6 出现之前，JavaScript语言没有内建支持模块化的语法，这导致前端开发复杂Web应用的时候，引用.js、组织文件、扩展功能、维护工程都显得效率低下，而且流程繁琐。然而对于一个复杂的Web应用，模块化编程可以良好的工作分工、功能扩展、工程维护，是软件开发方法论里面最基本的需求。那时候老一辈前端工程师们可以使用 IIFE 函数来实现模块化，很多库比如jQuery是这样实现的。

```javascript
let module = (function() {
    var _version = "1.0"; 
    var _name = "a-nice-module";

    function _log(x) {
        console.log(x);
    }

    function say(s) {
        _log(s);
    }

    return {
        name: _name,
        say: say
    };
})();

console.log(module._version);//>> undefined
console.log(module._log);//>> undefined
console.log(module.name); //>> a-nice-module
module.say("hello"); //>> hello
```

**模块本质上是封装，把模块内可访问的和不可以访问的区分得清清楚楚**。如上示例，模块之外是无法访问到模块内部的私有属性`_version`和私有方法`_log`的；而以一个对象的属性和方法的形式暴露内部属性`_name`和方法`say(s)`之后，然后将该对象返回给模块外部的调用者，那么在模块外部就可以访问它们了。

ECMAScript 6 吸收了老一辈前端工程师的各种优秀思想，最终采用了`import`和`export`内建语法支持模块化开发，基于浏览器底层的实现，使前端的模块化开发变得空前地规范和有效率起来，模块化开发终于迎来了应用热潮。

## 壹.2.14.2 AMD 和 CommonJS

AMD（Asynchronous Module Definition）常见于 RequireJS 时代，使用 `define` 声明模块及依赖，适合当时的浏览器异步加载场景。CommonJS 主要服务于 Node.js 等环境，典型形式是 `require()` 与 `module.exports`。

```javascript
// CommonJS：config.cjs
module.exports = { apiBase: '/api' };
// 使用：const { apiBase } = require('./config.cjs');
```

ES Modules（ESM）是语言标准，使用静态 `import/export` 声明依赖，便于静态分析、Tree Shaking 和浏览器原生模块加载。不能把 AMD、CommonJS、ESM 的模块加载时机和绑定语义一概而论。

## 壹.2.14.3 ECMAScript 6 的模块化

### 1.模块里的变量是以引用形式传递的

模块内变量的改变会同步到外面，更准确的说法是：ESM 的命名导出提供实时绑定（live binding），导入方可以观察到导出绑定的变化，但不能重新赋值导入绑定。举例说明如下：

```javascript
///////////////// module.js //////////////////////

let m = 0;
setTimeout(() => {
  m = 1;
}, 1000);
export function getM() {
  return m;
}
```

上面代码相当于传递下面的对象，其中\_m表示私有属性m

```javascript
{
  _m:0,
  getM:function(){
    return this._m;
  }
}
```

下面为入口文件 index.js ：

```javascript
/////////////// index.js //////////////////////////

import {getM} from "./module.js";
setTimeout(()=>{
    console.log(getM());
});
setTimeout(()=>{
    console.log(getM());
},2000);
//>> 0
//>> 1
```

### 2.模块嵌套

有些书籍称之为模块的继承，继承是面向对象编程的概念，本书更愿意称之为**嵌套**。

模块可以导入另一个模块的能力，再组合后导出：

```javascript
// math.js
export const double = x => x * 2;

// operations.js
import { double } from './math.js';
export const quadruple = x => double(double(x));

// main.js
import { quadruple } from './operations.js';
console.log(quadruple(3)); // 12
```

ESM 命名导入具有 **live binding（实时绑定）** 语义：导出模块更新其绑定，导入方读取时能观察到更新，但导入方不能重新赋值该绑定。这与“把变量包装成对象属性传过来”不是完全等价的解释。模块之间可能出现循环依赖，应避免初始化时读取尚未完成初始化的绑定。

## 壹.2.14.4 一个真实项目为什么一定要模块化？

假设一个网页有三份代码：商品价格计算、用户登录状态、页面渲染。如果三个功能都直接把变量挂在 `window` 上：

```javascript
window.total = 100;
window.user = '张三';
window.render = () => {};
```

任何脚本都有机会改动这些名字。项目一大，很容易出现命名冲突和隐式依赖。

模块化的目标是让每个文件明确声明“我提供什么”“我需要什么”，减少全局命名污染。

## 壹.2.14.5 用ES Module拆开购物车功能

```javascript
// cart.js
export function calculateTotal(items) {
  return items.reduce((sum, item) => sum + item.price * item.count, 0);
}
```

```javascript
// main.js
import { calculateTotal } from './cart.js';
console.log(calculateTotal([
  { price: 20, count: 2 },
  { price: 5, count: 3 }
])); // 55
```

浏览器里可以用：

```html
<script type="module" src="./main.js"></script>
```

注意：在本地直接用 `file://` 打开模块页面可能遇到跨源限制，建议使用本地开发服务器。模块路径、扩展名与 HTTP 响应 MIME 类型也要正确。

## 壹.2.14.6 ESM的“实时绑定”是什么意思？

```javascript
// counter.js
export let count = 0;
export function increment() { count++; }
```

```javascript
// main.js
import { count, increment } from './counter.js';
console.log(count); // 0
increment();
console.log(count); // 1
// count = 10; // 错误：导入方不能重新赋值这个绑定
```

这里并非“导出对象被复制了一份”，也不等同于“import 得到一个可随意修改的对象属性”。ESM 导入是**指向导出绑定的只读实时视图**：源模块更新这个绑定时，使用方能观察到新值；使用方却不能给导入绑定赋值。

## 壹.2.14.7 CommonJS和ESM什么时候会遇到差异？

老项目里可能会看到 CommonJS：

```javascript
// math.cjs
module.exports = {
  sum(a, b) { return a + b; }
};
```

```javascript
// main.cjs
const math = require('./math.cjs');
console.log(math.sum(2, 3)); // 5
```

Node.js 里也支持 ESM，但运行方式要看文件扩展名、`package.json` 的 `type` 配置和运行时版本。现代工具链可能在两种模块体系之间做互操作，但这并不意味着所有导入/导出写法可以原封不动互换。

## 壹.2.14.8 动态import解决什么需求？

大型后台系统可能只有少数人使用报表模块。可以等用户真正打开报表页面时再加载：

```javascript
async function openReport() {
  const report = await import('./report.js');
  report.render();
}
```

动态 `import()` 返回 Promise。打包工具通常也能利用它做代码分割。是否真的单独生成一个文件，取决于工具配置和目标环境。

**面试要点：** 模块化不仅解决“文件太多”问题，更重要的是建立明确依赖边界，让代码更容易复用、测试与维护。
