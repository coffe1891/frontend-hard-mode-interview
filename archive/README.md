# 历史稿件索引：为什么这些老文章没有直接删除？

话虽没错，可有些读者可能收藏过旧地址，搜索引擎也可能仍然收录。**直接删除最省事，给别人留下404也最容易。**

**后续处理原则：**

1. 有独特历史价值的，保留并标注背景。
2. 重复、内容有误但已经有新版的，优先让读者看新版。
3. 以后若决定移动或删除，先确认旧链接的访问情况和重定向方案，再动手。
